Nothing installed

No runtime, no driver, no agent on the host. A single Rust binary on the drive is the whole program, so a borrowed machine stays exactly as you found it.

Encrypted at rest

The volume is opaque until the password derives the key. Pull the drive and what is left is ciphertext, not a folder someone forgot to lock.

Goes where you go

Any machine that can run the binary can open the vault — the drive carries the program and the data together rather than depending on the computer.
